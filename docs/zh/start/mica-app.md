# Android 版 Mica 应用

Mica 应用在 Android 手机上配置和管理 Mica OS 设备。它做两件事：给处于蓝牙配置窗口中的设备设置要加入的网络，无需
连接设备的接入点；以及管理它能通过网络访问的设备，像控制台那样完成几项常见任务。它不需要账户，只与设备通信。

> status: shipped — evidence: `mica-app:lib/main.dart`, `mica-app:.github/workflows/release.yml`

## 1. 获取

应用以 APK 形式发布在 [micaoss/mica-app](https://github.com/micaoss/mica-app/releases)，只有一个文件
`mica-app.apk`，附带它的 `SHA256SUMS`；发布的标签就是应用的版本（当前是 `20261114-0429`）。它不在应用商店中。在
手机上下载 APK，能核对摘要就核对，Android 询问时允许浏览器或文件管理器安装它。

启动时应用读取最新发布，有更新的版本时提示下载它的 APK，覆盖安装当前版本。应用支持英文和中文。

没有 iOS 版本。

> status: shipped — evidence: `mica-app:lib/update.dart`, `mica-app:.github/workflows/release.yml`

## 2. 蓝牙配置

适用于带 WiFi 和蓝牙的产品（`cx3576.full`、`s905x5m.sd-full`、`s905x5m.emmc-full`），且设备的配置窗口打开时：每次
启动后 10 分钟内，或管理员在控制台中打开之后（[首次启动](first-run.md)第 5 节列出各窗口）。

1. **蓝牙配置**按主机名（`mica-xxxxxxxx`）列出处于配置中的设备。不需要蓝牙配对。同一时间只能有一部手机连接一台
   设备。
2. 已认领的设备会询问管理员密码，或者在管理员打开的窗口中，询问控制台显示的 8 位数字码。错误的回答会计数；
   太多次会把设备锁定一段时间。未认领的设备什么也不问。
3. 选择 **Wi-Fi**（从设备扫描到的网络中选择，或输入名称，然后输入密码）或**有线端口**（DHCP，或静态地址，可选
   网关和 DNS 服务器）。设备的无线电正在运行接入点时，加入网络会关闭接入点。
4. **完成配置。**应用显示设备的地址和指向其控制台的链接。对于接入点仍开着的未认领设备，它显示接入点的名称和
   密钥及二维码，并可以让手机加入它。

蓝牙只设置网络，别的什么也不设置：不设密码、不设主机名、不认领。未认领的设备之后在它的控制台或应用的网络管理
（第 3 节）中认领。未认领的设备在**完成**之前连接断开时，设备会撤销本次会话的修改。

已认领的设备，如果管理员自设备获得蓝牙配置功能以来还没有登录过控制台，就还不能核对密码：应用会提示先登录一次
控制台。

## 3. 通过网络管理

**通过网络管理**适用于手机能访问到的设备：在同一网络上、在设备的接入点上，或用网线连着手机。

- **找到它。**应用列出在手机所在网络上通过 mDNS 通告 `_mica._tcp` 的设备，以及你之前登录过的设备。关闭了通告的
  设备，或用网线连着手机的设备，通过输入地址访问：IP 地址、`<hostname>.local`，或设备登录提示中的 `Console` 行。
- **首次设置。**在未认领的设备上，应用设置管理员密码，此后它用于登录应用和控制台；在要求设备码的产品上，还会
  询问标签上的设备码。
- **登录**使用管理员密码。应用列出你之前登录过的设备，直到你忘记其中一台。
- **状态**：micad 是否应答，软件、板卡、部署和内核，运行时长，时钟是否同步，以及特性。
- **网络**：保存的 Wi-Fi 网络（添加、删除）和有线端口（DHCP 或静态地址）。
- **系统设置**：修改管理员密码；开关 SSH 服务器，添加或删除其授权密钥。

使用 HTTPS 时，应用记住设备第一次出示的证书，有其他证书应答时发出警告并显示其指纹；只有在你知道设备被重置或其
证书被替换时才信任新证书。Web 模式为 `local` 的设备不能通过网络管理。

> status: shipped — evidence: `mica-app:lib/console/discovery.dart`, `mica-app:lib/manage_page.dart`, `mica-app:lib/manage_settings.dart`

## 4. 局限

- **未在硬件上运行过。**协议、设备端和客户端都用对方的参考实现做了测试；还没有在实体板卡上进行蓝牙配置的记录
  （[首次启动](first-run.md)第 5 节）。
- 只有 Android。没有低功耗蓝牙的手机改用设备的接入点配置。
- 应用只覆盖控制台的一小部分。其他一切（更新、容器、服务、存储、访问、日志）在控制台、API 或
  [`mica`](../operate/mica.md) 中。

> status: unsupported
